# ChipQC Guardian: demo film

This branch holds one file, the demo film of [ChipQC Guardian](https://github.com/yy5652-hash/chipqc-guardian-ai4s). It is kept apart from `main` so that cloning the code stays small.

- `ChipQC_Guardian_Demo_Video.mp4`: 3 min 22 s, 1920 × 1080, H.264 and AAC, 63 MB
- The same film on YouTube: https://youtu.be/TDwHyMEzVOM
- The same film on Bilibili: https://www.bilibili.com/video/BV1h1Hd6vESY

The film is made from the system and the data in the repository: the frames, the evidence maps, the acquisition gate, the review console, the browser demo and the measured results. The microscope images come from the Organ-on-a-Chip (OOC) Image Dataset (Movčana et al., Zenodo, [doi:10.5281/zenodo.10203721](https://doi.org/10.5281/zenodo.10203721), CC BY 4.0). The narration is a synthetic voice (Kokoro-82M, Apache-2.0) and the soundtrack was synthesised by a script.

Code, model, results and report are on the [`main` branch](https://github.com/yy5652-hash/chipqc-guardian-ai4s).
